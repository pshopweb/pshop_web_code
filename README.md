# 🛒 PShop - E-Commerce Web Application

A complete, modern e-commerce web application built with HTML, CSS, and JavaScript.

## 🚀 Features

- **Home Page** - Banner slider, categories, product grid with filters & search
- **Authentication** - Login & signup with form validation
- **Product Details** - Full product view with quantity selector
- **Shopping Cart** - Add/remove items, quantity controls, order summary
- **Checkout** - Multi-step checkout (Shipping → Payment → Confirm)
- **Order History** - View and filter past orders
- **User Profile** - View and edit profile information
- **Messages** - Chat-style messaging system
- **Settings** - Password change, notifications, theme settings
- **Responsive Design** - Works on all devices
